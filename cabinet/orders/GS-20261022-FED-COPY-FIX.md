## 裁断

| # | 项 | 裁断 |
|---|----|------|
| **C1** | 「腿」案怎么改 | 英文 *leg*（回购 / 逆回购的一笔交割端）中文**一律**用 **「端」**，不用「腿」。固定对译：*starting / opening leg* → **起始端**；*closing leg* → **到期端**；机制叙述可写「起始端交割 / 到期端交割」。业主截图句改为：**「起始端：联储支付买券款」**；对句 **「到期端：联储收回本息价款」**（冒号可保留，忌「起始端联储…」粘连难读）。 |
| **C2** | 「现金腿」等 | *cash leg* → **现金端**（或「现金交割端」）；*security leg* → **证券端**。禁止「现金腿」「分腿金额」——改 **「分端金额」** 或「起止两端各自金额（PDF 未给则不写）」）。 |
| **C3** | *unwind* | 不作「解开」类直译。ON RRP / repo 到期回转：用 **「到期回转」** 或 **「到期端回转」**；与 PDF「次日 unwind」对齐时中文优先「到期回转」。 |
