## 裁断（硬）

### A · 内外部定义（BS 专用 · 钉死）

| # | 项 | 裁断 |
|---|----|------|
| **A1** | 用途 | 仅服务业主方法论：**单看橙色（内部）判断 BS 各方面是否被美联储体系覆盖**。不是制度图六色，也不是证据链 `isExternal`。 |
| **A2** | **内部（橙）** | 美联储**体系机关**：`BOG`、`FOMC`、`DESK`；一切 `RB-*`（含 `RB-ALL`、`RB-01`…`RB-12`、`RB-BOARD`、`RB-PRES`、`RB-ADV`）；以及图中明确属 Fed 机关/委员会且非对手方的节点（若有漏网同规则补入，不得凭感觉扩到银行/财政部）。 |
| **A3** | **外部（青）** | 体系外主体与对手方，至少含：`TREASURY`、`TGA`、`CONGRESS`、`PUBLIC`、`DEP-INST`、`MEMBER-BANKS`、`PRIM-DEALERS`、`NONBANK-CP`；以及市场/公众/国会侧其它对手方。 |
| **A4** | 边界钉死（业主曾疑） | **`TGA` = 外**（财政部在联储的账户，非 Fed 机关）。**`MEMBER-BANKS` = 外**（会员银行，非 System 机关）。**`DEP-INST` = 外**（存款机构准备金对手方）。**`TREASURY` / `PUBLIC` / 交易商与非银 = 外**。**`DESK` / `RB-ALL`（及 RB 族）= 内**。 |
| **A5** | 与 `isExternal` | **禁止**把现有 `isExternal`（轮值席 / evidence `status===external`）直接当 BS 内外。另立派生：如 `bsFedInternal(node)` 或数据字段 `bs_scope: "internal"\|"external"`（实现择一；真源优先可计算则不必改 JSON，规则须单点可测）。 |
| **A6** | 未分类 | 新节点若既非 A2 亦非 A3：默认 **外**，并在勾稽报告记一行「待核」；不得静默当内。 |
